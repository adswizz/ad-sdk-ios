# How to migrate to AdswizzSDK v7.9.0+

The **_AdswizzSDK_** v7.9.0 release supports the latest Apple Privacy guidelines. In this guide you will find everything you need to know on how to update your application with the changes brought by **v7.9.0 and later**. For the latest changes, please visit the [Changelog](iOS/CHANGELOG.md).

## What changed
The **_AdswizzSDK_** v7.9.0 introduces its own [Privacy Manifest](iOS/SDKPrivacy/PrivacyManifest.md) according to the Apple Privacy guidelines, as well as a detailed section for the [Data Usage Policy](iOS/SDKPrivacy/DataUsagePolicy.md). Additionally, starting with v7.9.0, **_AdswizzSDK_** now code signs its binary XCFrameworks. More details at [Code Signing](iOS/SDKPrivacy/CodeSigning.md).

Here is a breakdown of the implications from the latest changes.

### Prerequisites
* Xcode version bumped to 15.2+
* Swift version bumped to v5.9.2+ if the integration app uses Swift or Objective-C

## What you may need to do
Considering the changes above, and although we always recommend updating **_AdswizzSDK_** to the latest version, in order to migrate to v7.9.0, your application should be able to support and compile using `Xcode 15.2` or newer.

Here are known scenarios which can help you with troubleshooting the migration to v7.9.0 and newer releases.

### Framework Signature Validation Failed
You may encounter errors from Xcode similar to:

> The signature of “AdswizzSDK.xcframework” cannot be verified.

> The signing certificate has been revoked (CSSMERR_TP_CERT_REVOKED)

> The signature of “AdswizzSDK.xcframework” cannot be validated and may have been compromised.

**_AdswizzSDK_** v7.9.0 and later are distributed as cryptographically signed XCFrameworks. You can read more at [Code Signing](iOS/SDKPrivacy/CodeSigning.md) or in Apple's documentation: [Verifying the origin of your XCFrameworks](https://developer.apple.com/documentation/xcode/verifying-the-origin-of-your-xcframeworks).

The certificates we use for signing have a lifetime of one year. During the process of updating our certificate on 18th of April 2024, we made a mistake and revoked the old certificate, leading to **_AdswizzSDK_** v7.9.0 not having valid signatures. **_AdswizzSDK_** v7.9.1 and later have valid signatures. We recommend updating to the latest version of **_AdswizzSDK_**.

To manually resolve this issue for version `7.9.0`, remove the `_CodeSignature` folder in all **_AdswizzSDK_** `.xcframeworks`. This results in the frameworks being unsigned. However, because the **_AdswizzSDK_** `.xcframeworks` are distributed via Github, and by using HTTPS, the download likely provides an acceptable level of security. You may have to select `Accept Change` due to the removal of the signature for building to succeed again. See the [Diagnose failures caused when a code signature is removed](https://developer.apple.com/documentation/xcode/verifying-the-origin-of-your-xcframeworks#Diagnose-failures-caused-when-a-code-signature-is-removed) section in Apple’s documentation for more details.
