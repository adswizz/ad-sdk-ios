# How to migrate to AdswizzSDK v7.10.0+

The **_AdswizzSDK_** `v7.10.0` introduces [AdswizzSDKPrivacyDataKit](iOS/SDKPrivacyDataKit/AdswizzSDKPrivacyDataKit) as a replacement for the previously used *AdswizzSDKPrivacyData* source based framework. In this guide you will find everything you need to know on how to update your application with the changes brought by **v7.10.0 and later**. For the latest changes, please visit the [Changelog](iOS/CHANGELOG.md).

## What changed
The **_AdswizzSDK_** `v7.10.0` deprecates the *AdswizzSDKPrivacyData* source based framework in favour of the optional [AdswizzSDKPrivacyDataKit](iOS/SDKPrivacyDataKit/AdswizzSDKPrivacyDataKit) which makes **_AdswizzSDK_** easier to install without any other mandatory dependencies. Furthermore, it mitigates compatibility issues when the application runs on a more recent Xcode version than the one used to generate AdswizzSDK binaries.

Here is a breakdown of the implications from the latest changes.

#### Dependencies
**_AdswizzSDK_** v7.10.0 and later does not use the previously required mandatory dependency of *AdswizzSDKPrivacyData* source based framework. It now uses the **optional** [AdswizzSDKPrivacyDataKit](iOS/SDKPrivacyDataKit/AdswizzSDKPrivacyDataKit) framework components. Read more on how to [integrate](iOS/SDKPrivacyDataKit/IntegratingAdswizzSDKPrivacyDataKit) the components from **_AdswizzSDKPrivacyDataKit_**.

## What you need to do
Considering the changes above, and although we always recommend updating **_AdswizzSDK_** to the latest version, in order to migrate to v7.10.0, you should remove the old *AdswizzSDKPrivacyData* dependency from your application target. Depending on what method you chose to install your current **_AdswizzSDK_** `pre-7.10.0`, here are known scenarios which can help with the migration to `v7.10.0` and newer releases.

#### Swift Package Manager
Make sure you remove your **_AdswizzSDK_** and **_AdswizzSDKPrivacyData_** from your application package dependencies and [reset](/iOS/SDKiOS/GetStarted#troubleshooting) Swift Package Manager caches before following the [Swift Package Manager](/iOS/SDKiOS/GetStarted#swift-package-manager) guide to update to `v7.10.0` and newer versions.
#### Cocoapods
Remove the **_AdswizzSDK_** and **_AdswizzSDKPrivacyData_** pods from your application workspace and also remove the custom `post_install` hook from your Podfile:

```ruby
    post_install do |installer|
       installer.pods_project.targets.each do |target|
            if target.name == "AdswizzSDKPrivacyData"
             target.build_configurations.each do |config|
              path = config.base_configuration_reference.real_path
              update_xcconfig(path, { "BUILD_LIBRARY_FOR_DISTRIBUTION" => "YES"
    # Exclude senstive API. Uncomment the line bellow and exclude what permission you don't want to add to your app.            
    #                               , "SWIFT_ACTIVE_COMPILATION_CONDITIONS" => "NO_IDFA_ACCESS NO_SPEECH_ACCESS NO_CONTACTS_ACCESS NO_CALENDAR_ACCESS NO_CAMERA_ACCESS NO_LOCATION_ACCESS NO_MICROPHONE_ACCESS NO_MOTION_ACTIVITY_ACCESS"
                                    })
             end
           end
       end
    end

    def update_xcconfig(path, new_values)
      build_settings = Hash[*File.read(path).lines.map{|x| x.split(/\s*=\s*/, 2)}.flatten]
      new_values.each { |k, v|
        build_settings[k] = "#{v}\n"
      }
      File.open(path, "w") do |file|
        build_settings.each{ |k, v|
          file.write("#{k} = #{v}")
        }
      end
    end
```

Now you are ready to follow the updated [Cocoapods](/iOS/SDKiOS/GetStarted#cocoapods) guide to update to `v7.10.0` and newer versions.
#### Carthage
Remove the **_AdswizzSDK.xcframework_**, **_AdswizzSDKCore.xcframework_** and **_AdswizzSDKPrivacyData.xcframework_** binaries from your application workspace and read the updated [Carthage](/iOS/SDKiOS/GetStarted#carthage) guide to update to `v7.10.0` and newer versions.

## What you may need to do
Here are some changes that _may_ be needed to support the update to **_AdswizzSDK_** `v7.10.0`.

#### You application uses the AdswizzSDKPrivacyData
If in your application you are already using the **_AdswizzSDKPrivacyData_** interface, you will need to change the import at the top of your source files that use the symbols defined within the `AdswizzSDKPrivacyData` namespace (e.g: `AdswizzSDKPrivacyData.shared`, `PermissionType`, `PermissionValue` and so on).<br>
Adding the correct `import` will solve the issue:
```swift
import AdswizzSDKPrivacyData // -> import is not available anymore
import AdswizzSDKPrivacyDataCore // -> correct import

class MyClass {
...
}
```
