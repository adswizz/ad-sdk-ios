# AdswizzSDK Pinpoint Analytics

This guide is addressed to iOS developers that are interested to integrate the **_AdswizzSDKPinpointAnalytics_** in their iOS application, in order to take full advantage of the out-of-the-box support for **_Amazon's Pinpoint_** service and to conveniently log **_AdswizzSDK_** [Analytics events](/iOS/SDKiOS/AdswizzAnalytics) to the AWS dashboard. For more details on what Pinpoint is and its capabilities, please visit the Amazon Pinpoint [product pages](https://aws.amazon.com/pinpoint/) and [technical documentation](https://docs.aws.amazon.com/pinpoint/latest/developerguide/welcome.html) guide.

## What is the AdswizzSDKPinpointAnalytics?
**_AdswizzSDKPinpointAnalytics_** is an optional framework which acts as a wrapper for the AWS Pinpoint Analytics service. It allows your application to easily log and send all [Analytics events](/iOS/SDKiOS/AdswizzAnalytics) generated by **_AdswizzSDK_** to the Amazon servers, in order to process them by the Pinpoint service. You will get access to the entire range of capabilities that Pinpoint offers, including but not limited to:
* cohorts
* funnels
* demographics
* campaigns
* user journeys

**_AdswizzSDKPinpointAnalytics_** is dependent on the **_AdswizzSDK_** in order to function properly.
> **Note**
> All [Analytics events](/iOS/SDKiOS/AdswizzAnalytics) that will go through the Pinpoint connector are relative to the **_AdswizzSDK_** integration in your application. 

## What it does do
**_AdswizzSDKPinpointAnalytics_** enhances **_AdswizzSDK_** Analytics capabilities to log and send [Analytics events](/iOS/SDKiOS/AdswizzAnalytics) to the AWS Pinpoint services. Thus, **_AdswizzSDKPinpointAnalytics_** relies on a proper integration of the **_AdswizzSDK_**, version **7.8.0 or later**.
By using its built-in publicly exposed components, **_AdswizzSDKPinpointAnalytics_** will also acdess and collect device data from the listener to be able to send appropriate information to the AWS servers for better Analytics capabilities. The information accessed and collected by the **_AdswizzSDKPinpointAnalytics_** is available in the [Privacy](/iOS/SDKPinpointAnalytics/Privacy) section.

## What it doesn't do
**_AdswizzSDKPinpointAnalytics_** can't function without the **_AdswizzSDK_**. Its communication is with the **_AdswizzSDK_** and through the network calls to the AWS Pinpoint service. It is important to note that **_AdswizzSDKPinpointAnalytics_** is a companion framework of the **_AdswizzSDK_**.

## Prerequisites for a successful integration
In order for the **_AdswizzSDK_** to use the **_AdswizzSDKPinpointAnalytics_** in your application, you need to make sure that your organization has access to the AWS Pinpoint account on Amazon which is managed by Adswizz. In order for **_AdswizzSDKPinpointAnalytics_** to be able to connect to your AWS Pinpoint project, you should contact your Adswizz partner integration manager and request the following information to help you setup the Pinpoint connection:
* `region` - the AWS region that you are targeting
* `projectId` - the project identifier in the AWS Pinpoint dashboard 
* `identityPoolId` - the token used by **_AdswizzSDK_** to authenticate and sign the AWS API calls

Here is the list of requirements when integrating **_AdswizzSDKPinpointAnalytics_**:
* make sure your organization has access to the information above to connect to Amazon Pinpoint service
* make sure you update your **_AdswizzSDK_** integration to **v7.8.0 or later**
* make sure you install **_AdswizzSDKPinpointAnalytics_** through the supported installations via Cocoapods, Carthage or manually

For more details on how to integrate **_AdswizzSDKPinpointAnalytics_**, please visit the [Integrating AdswizzSDK Pinpoint Analytics](/iOS/SDKPinpointAnalytics/IntegratingAdswizzSDKPinpointAnalytics) section.
